wire: code.outline
params: OutlineParams
result: OutlineResult
on: machine

A file's functions, types, sections and blocks in file order, each with its kind, name, lines and depth, by line rules for Rust, TypeScript/JavaScript, Python, Markdown and TOML and by indentation for other files.
Over 2,000 symbols or 256 MiB is `LIMIT`.
`machine` reads it there.
