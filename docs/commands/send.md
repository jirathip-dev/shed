`shed send <t> <text> [--no-paste] [--no-enter] [--draft-wait S]` / `shed keys <t> enter esc ctrl+c…`

Paste text then press enter (bracketed when the program asks for it), or press keys.
Sends go in whole, one at a time, and wait while a person attached has an unsent line (60 s by default, then the send fails and writes nothing).
